## Difference-summary experiments

`plot_summary_differences.py` regenerates the 5–16/8–64/E2E adaptation-time
comparison and PEBS sensitivity comparison. The model bundle contains the full
40-split grid at demapper pretraining epochs 5 and 10. For a different source
budget, change `pretrain.dem_epochs` explicitly and start a new run; keep the data,
optimizer, batch-order convention, and timing environment fixed.

## Model and data naming

Public case `Paris_P1` uses the archived internal position `paris_fixed_P3`;
public `Paris_P2` uses `paris_fixed_P2`. The internal IDs remain unchanged because
they are part of the random-stream derivation. `SF` means San Francisco. RT source
links are 128 LOS positions per city; target cases use the frozen NLOS responses
and declared narrowband interference. No target is selected again during a run.

`CNN` in configuration IDs names the original E2E CNN receiver. Plot legends use
`E2E`; the backbone comparison retains `CNN`, `MLP`, and `Transformer`. The internal
backbone key `mixer` is retained for compatibility with saved MLP weights.

## Retraining versus archived-result reproduction

The figure workflow consumes the archived measurements. GPU commands produce a
new experimental record and never overwrite those measurements. All 40 PEBS
configurations execute their full trajectory; main experiments stop at the first
validation hit. A model that fails the target within its budget retains its final
BER and `target_reached=false`. Zero observed errors remain zero in CSV files;
plotting scripts mark them at the finite counting resolution where required by a
logarithmic axis.
